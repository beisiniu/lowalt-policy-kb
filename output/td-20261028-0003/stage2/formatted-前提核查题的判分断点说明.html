无法判分的题量（占 39%） 穿透率的报告上限 不可归因的分差

新题库 46 道题中，18 道前提核查题（false_premise）没有旧条款，而现有评测的全部时序指标都以"旧条款是否被召回"这一个布尔量为轴，因此这批题在指标上不可度量。程序不会报错，但穿透率上限被压到 60.9%，加权得分中还混入约 0.078 的拒答残差。下文给出四处断点的定位与三条修复路径，建议按题型拆分报告口径。

一、问题的性质

新题库 benchmark_tq2.json 共 46 道题，其中 18 道的 conflict_type 为 false_premise（下称前提核查题）。这 18 道题目前无法进入 evaluate.py 的正常评测流程。

需要先明确问题性质。

  这不是程序报错，而是度量失效。如果代码抛出异常，问题会立刻暴露；实际情况是程序可以完整跑完、不报任何错误，输出的指标却在数学上失去了意义。这类问题比报错更危险，因为结果看起来是正常的数字，可能被直接用于结论或投稿。

因此"评估没跑"这个判断，准确表述是：在给定现有代码的前提下，跑出来的数字不可解释，所以选择不跑，而不是技术上跑不起来。

二、现有评测以「一对新旧条款」为计量单位

要理解断点在哪，先要看清这套评测的计量单位。

evaluate.py 的实验设计只改变一个变量：检索到同样的 Top-K 后，Naive 分支把条款原样拼进上下文，Temporal 分支先按生效日期与失效日期过滤再生成。为了让两组差异可以归因到"是否过滤"，程序在每题上计算一个布尔量——old_clause_penetrated（旧条款穿透），含义是"这道题的 Top-K 里，有没有召回到那条已经失效的条款"。

这个布尔量由 clause_matches 判定（rag_eval/temporal.py:165），结果在 evaluate.py:591 写入：

"old_clause_penetrated": old_rank is not None,

全部时序指标都挂在这一个布尔量上：穿透率的分子是它为真的题数，条件毒化率的分子要求它同时成立，旧条款拦截率的分母就是它为真的题数。换句话说，这套评测的计量单位不是"一道题"，而是"一对新旧条款"——每道题必须同时具备旧条款和新条款，指标才有定义。

三、前提核查题缺少其中一半

以 TQ2-FP01 为例，题目是"我在上海开婚庆公司，想用无人机做婚礼航拍，能申请婚庆航拍专项补贴吗？"标准答案是"上海市现行政策中没有这一补贴项目，不能申请"。它的字段结构是：

  1. old_clause_id = ""、old_clause_text = ""：没有旧条款。
  2. new_clause_id 有值，但这条现行条款的作用是反证——它只支持 eVTOL 与工业级整机生产制造，因此可以推出不存在婚庆航拍运营补贴。
  3. answer_type = "refuse"，gold_evidence.negative = true，fake_name = "婚庆航拍无人机专项运营补贴"。

两类题在结构上不同源。前提核查题测的是政策清单的封闭性判断，属于幻觉与顺从性范畴；条款对照题测的是版本时效判断，属于时序推理范畴。把它们放进同一套按"条款对"设计的指标里，就会出现下面四处断点。

四、四处具体断点

四处断点分属两个层面：4.1 至 4.3 位于判分路径上，分别破坏加载校验、穿透判定与标签定义；4.4 位于实验设计层，破坏处理组与对照组的可比性。

4.1　加载能通过，因为空字符串伪装成了有效值

load_benchmark 在加载时校验 6 个必填字段，其中包括 old_clause_text，缺失即抛 ValueError。这 18 道题有这个键，只是值为空字符串，因此校验全部通过。

这一点值得单独说明：如果当初生成题库时省略该字段，程序会在加载阶段立即报错，问题当场暴露。正因为用了空串而非缺失，它通过了所有存在性检查。这是数据工程中的典型陷阱——把缺失值编码成空值，让"没有"看起来像"有，但是零"。

4.2　穿透判定恒为 False，而且不是匹配失败

evaluate.py:552 调用 clause_matches，其内部逻辑是：

if expected_id and candidate.id == expected_id:   # expected_id 为空，跳过
    return True
a = normalize_for_match(candidate.text)           # 候选条文，非空
b = normalize_for_match(expected_text)            # 空字符串，得到空串
if not a or not b:                                # 命中
    return False                                  # 恒为 False

if not a or not b: return False 本身是正确的防御——空文本不应被判为匹配。问题在调用方：它把两件性质不同的事编码成了同一个 False。

  • 旧条款存在，但没被召回：穿透为 False。这是一个有信息的阴性结果，说明模型确实躲过了过期条文。
  • 这道题没有旧条款：穿透不适用，是一个不存在的量。

现在后者被当成了前者。统计上这称为"把缺失当作零值"，会系统性压低所有以它为分母或分子的比率。

4.3　正确答案在标签体系中没有唯一定义

JUDGE_SYSTEM 把回答分为四类：POISONED（旧政策毒化）、CORRECT（正确）、REFUSED（拒答）、OTHER_ERROR（其他错误）。其中 REFUSED 的定义是"明确拒答、说资料不足或无法确定，没有给出可判错的结论"，并明确规定"拒答不能算 CORRECT"。

对一个正确的回答——"上海没有婚庆航拍补贴，现行政策只支持整机制造"——两个类别都说得通：

  • 按 CORRECT 的定义（核心结论与标准答案一致），它与标准答案完全一致，应判正确，得 1.0 分。
  • 按 REFUSED 的定义（否定性表述、没有给出可判错的结论），它同样符合，得 0.2 分。

于是三道裁判在这类题上会系统性分歧，三裁判多数票不是在消解噪声，而是在决定这道题值 1.0 还是 0.2。更麻烦的是，这个分歧方向有系统性偏差：Temporal 分支过滤后若无可依据条款，会走 _refuse 节点（rag_eval/temporal_graph.py:135 的 route = "generate" if keep else "refuse"），其话术是"知识库中没有检索到与该问题相关的政策条款，无法给出确定结论"，字面上正是 REFUSED 的定义。一个真正完成封闭性判断的回答（"查过了，政策里确实没有这一项"）和一句"我没检索到"，在计分上被压成同一个值。

反向的问题同样存在。当模型顺着假前提编造申请流程和材料清单时，严格按定义不能判 POISONED——该类别要求"错误来自使用了旧条款、旧版标准"，而这题没有旧条款。只能落入 OTHER_ERROR，但该类别还同时收纳了算错数、答非所问、混用其他地区数值等情况。"顺从假前提"这个特定失败模式，在四分类里没有独立的位置，想单独报告幻觉率做不到。

4.4　这类题在实验设计上属于未接受处理的样本

_temporal_check（rag_eval/temporal_graph.py:113）按 valid_from、valid_to 剔除条款。前提核查题的 Top-K 中通常不含过期条款，dropped 为空，过滤动作不发生。

也就是说，这 18 道题在实验上是未接受干预的样本，却和 28 道真正接受干预的样本被算进同一个均值。这会向零稀释组间差异：即使时序过滤完全有效，混入约四成的无干预样本后，测出的效应量也会明显小于真实值。

五、直接运行的数值后果

以下为基于题量与分值的算术推演，非实测结果。

  1. 穿透率上限被压到 60.9%。分子最多 28（18 道恒不计），分母固定 46，因此报告值不可能超过 28÷46。上一版题库 96 道题全部具备旧条款文本，口径完全不同，两个版本的穿透率不可直接比较。
  2. 总体毒化率被稀释。分母为 46，其中 18 道在结构上不可能被旧条款毒化，等于把约 39% 的"地板"混进了比率。
  3. 条件毒化率本身计算正确（分子分母同集合，只含条款题），但它与总体毒化率并列在同一张表中时，读者会默认二者是全集与条件集的关系，实际二者相差了整块前提核查题。
  4. 加权得分混入了与时序无关的分差。若这些题被判 REFUSED，每题无条件贡献 0.2 分，合计 0.2×18÷46 ≈ 0.078。由于拒答话术与 REFUSED 定义高度重合，这个残差会系统性偏向 Temporal 分支，容易被误读为"时序架构的收益"。

  最需要警惕的是第 4 项：增益来源不可归因。报告里若出现"Temporal 相比 Naive 提升 0.078"，其真实来源是拒答倾向，而非时序纠错能力。

七、结论

这 18 道前提核查题在方法上有独立价值——它们测的是政策清单的封闭性判断，正是不受时点影响、也最容易被大模型幻觉污染的一类问题。问题不在题目本身，而在于现有评测的计量单位是"一对新旧条款"，而这批题只有一半。

处理原则应当是：不与条款对照题混算，不为迁就现有指标而削减题型，而是按题型分别定义判分路径与报告口径。同时应修正 judge_answer 中固定拼接"旧条款（已失效）"的提示词构造——这类题会向裁判呈现一个标题完整、内容为空的区块，本身即构成干扰。
