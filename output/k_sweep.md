## 指标定义

| 指标 | 定义 |
|---|---|
| 现行条款召回率 | Top-K 里召回到现行条款的题占比 |
| 旧条款穿透率 | Top-K 里召回到已失效条款的题占比 |
| Naive 毒化率 | Naive 判 POISONED 的题占比 |
| Temporal 毒化率 | Temporal 判 POISONED 的题占比 |
| 严格拯救率 | Naive 毒化且 Temporal 正确的题 / Naive 毒化题数 |
| 毒化消除率 | Naive 毒化且 Temporal 不再毒化的题 / Naive 毒化题数 |
| Temporal 拒答率 | Temporal 判 REFUSED 的题占比 |
| 加权增益 | Temporal 加权得分 − Naive 加权得分 |

## k 的选择

**判据**：现行条款召回率 ≥ 90% 且旧条款穿透率 ≥ 90%，取满足条件的**最小 k**。

**结果：k = 9**（召回 90.3% / 穿透 96.8%）。最小 k 优先，因为上下文更短、推理成本更低，且更接近真实部署配置。

为什么不用准确率挑 k：准确率受裁判噪声影响，在同一测试集上按准确率挑 k 等于在测试集上调超参数，会高估效果。检索层指标（召回率/穿透率）只由向量检索决定，同一 k 下完全可复现，适合作为选择依据；准确率只用于**验证**选定 k 的表现。

满足条件的 k 共 12 个：k=9、k=10、k=11、k=12、k=13、k=14、k=15、k=16…。

## 读法

- **旧条款穿透率**随 k 单调上升是必然的（候选越多越容易包含旧条款）；关键不是它，而是它上升的同时 **Naive 毒化率**是否也跟着上升。
- **现行条款召回率**是 Temporal 分支的弹药量：k 太小时过滤完手里没牌，只能拒答；它上来之后，严格拯救率才有上升空间。
- **严格拯救率**（毒化→正确）与 **毒化消除率**（毒化→不再毒化）的差额，就是「过滤了但答不出」的部分，反映检索层的天花板。
- 若 **Temporal 毒化率**在某个 k 之后重新抬头，说明候选过多引入了新的过期条款，该 k 即为上限。
